# TASK-01 — Laravel Project Bootstrap

**Phase**: 1 — Foundation  
**Depends on**: Nothing  
**Estimated effort**: 2 hours

---

## Description

Create the Laravel 12 project, configure the environment, and install all required packages. This task produces a bootable Laravel application with no application logic — just the skeleton, configuration, and vendor dependencies.

---

## Affected Files

### Create
- `composer.json` — project manifest with all required dependencies
- `.env` — local environment variables (DB, session, API keys)
- `.env.example` — committed env template
- `config/app.php` — app name, timezone, locale
- `config/database.php` — MySQL connection defaults
- `config/session.php` — session lifetime (7200 seconds)
- `config/services.php` — Lambda and FaceXAPI keys
- `config/cors.php` — CORS configuration (permissive for API parity)
- `bootstrap/app.php` — middleware registration

### Modify
- `composer.json` — add autoload files entry for custom helper
